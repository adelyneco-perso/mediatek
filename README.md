# Mediatek

Mediatek est une application full-stack de gestion de collection personnelle de médias, principalement des livres et des vinyles.

Elle permet à un utilisateur de gérer sa collection, sa wishlist et ses listes personnalisées, tout en pouvant partager publiquement certaines informations par lien ou export.

## Stack technique

### Frontend

- React
- Next.js
- TypeScript

### Backend

- PHP
- Symfony
- API Platform

### Base de données

- PostgreSQL
- Doctrine
